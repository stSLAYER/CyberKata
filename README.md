## Lessons

### [Brute Force with Hydra](Lessons/Brute%20Force%20with%20Hydra/)

Learn how Hydra commands are constructed by completing four local login challenges:

- Find a password for a known username.
- Find a username for a known password.
- Test username and password lists together.
- Identify success from the server response.

[Open the lesson](Lessons/Brute%20Force%20with%20Hydra/) · [Download the lab ZIP](Lessons/Brute%20Force%20with%20Hydra/CyberKata-Hydra-Dojo.zip)

## How CyberKata labs work

1. Download and extract the lesson ZIP.
2. Start the local target with Python.
3. Open the lab interface in your browser.
4. Follow the guided exercises from your terminal.
5. Complete the final challenge independently.

The labs are designed to run locally and avoid unnecessary setup. The Hydra Dojo uses only Python's standard library—no Docker, database, package installation, or administrator access is required to host it.

## Use responsibly

These projects are intentionally vulnerable training environments. Run them only on your own machine or in an environment where you have explicit permission. Never use the commands against public websites, accounts, or infrastructure you do not own.
