# Security and responsible use

CyberKata contains intentionally vulnerable applications for local education.

## Safe use

- Run the labs only on systems you own or are explicitly authorised to test.
- Keep VM-access mode on a trusted private network.
- Do not expose a lab port to the public internet.
- Stop the server when the exercise is complete.

## Reporting an unintended issue

If you discover a vulnerability that escapes the intended local lab boundary, do not publish exploitation details in a public issue. Contact the repository owner privately through their GitHub profile so the problem can be assessed first.

The deliberately weak lesson logins, training credentials, and response markers are part of the exercises and are not security defects.
