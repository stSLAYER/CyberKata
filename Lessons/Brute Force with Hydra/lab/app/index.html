02 CONTROLRUN FLAGS
-s 8080CUSTOM PORT

Send attempts to the lab's listening port.

-t 4TASK COUNT

Run four attempts in parallel. Keep this modest in a local lab.

-fSTOP ON SUCCESS

Finish after the first valid credential is found.

-VVERBOSE ATTEMPTS

Show every login attempt while you learn.

-IIGNORE RESTORE

Start clean instead of resuming an old Hydra session.

03 MODULEHTTP FORM GRAMMAR
/api/login/1:username=^USER^&password=^PASS^:F=ACCESS_DENIED
^USER^

Hydra replaces this with each username.

^PASS^

Hydra replaces this with each password.

F=TEXT

The response text that proves an attempt failed.

S=TEXT

The response text that proves an attempt succeeded.

RULE: define either a reliable failure marker or a reliable success marker. Hydra needs one clear signal to separate misses from hits.
